# 智能问诊降级策略

当患者档案、病历或就诊记录的工具查询已成功，但文本模型不可用、超时或返回空内容时，系统不能只返回“已查询到 N 条记录”。

对于患者档案聚合查询，系统使用确定性的记录摘要降级：仅复述工具已返回的患者姓名、已登记过敏史、最近两条病历和最近两条就诊记录，不生成新的诊断、用药或随访结论。回答开头会明确标注“模型服务暂不可用，未进行额外推断”。

模型失败仅在服务端记录异常类型，不记录问题全文、病历原文或患者标识。前端应把这类内容呈现为可用的“基于记录的降级回答”，而不是声称模型已经生成了完整分析。

其他工具查询的降级策略也应遵循同一原则：优先返回已核验的结构化事实；若没有可安全展示的事实，再告知当前无法完成回答。
