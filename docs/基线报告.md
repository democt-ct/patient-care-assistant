## 2. 当前链路状态（基线快照）

### 路由

- 无独立 `RetrievalRoute`；任务归类依赖旧意图识别（`chosen_tool`）。
- 结构化事实直答覆盖：紧急联系人、过敏史、用药、就诊医生、复诊、诊断/手术关键词。
- 其余问题进入 LLM Agent 链路，无任务级禁止动作约束。

### 安全拦截

- `medical_safety_gate` 在 Graph 首节点执行：紧急症状（胸痛、呼吸困难、意识异常等）→ `emergency`；剂量、停药、换药、相互作用等 → `clinician_review`。
- 危险信号由正则规则枚举，覆盖情况以 `tests/test_medical_safety_gate.py` 为准。

### 证据与引用

- `verify_evidence` 为观察桩：只记录 `sufficient` 布尔，不产出 EvidencePack，无冲突检测。
- 结构化直答路径在输出装配前提前返回，绕过了统一输出契约（阶段 A 修复）。
- 无独立引用校验；`hallucination_guard` 只负责实体与危险内容检测。

## 4. 基线结论

当前版本已经具备任务路由、EvidencePack、证据策略、引用校验和统一输出契约，可用于演示「事实直答」「安全拦截」与「冲突提示」。29 条独立测试集实测：27 通过（93.1%），安全类指标（高风险召回 / 危险建议拦截 / 冲突发现）100%，不必要拒答 0%，P95 5.6s。待办：修复 2 条证据不足拒答措辞（幻觉检查 TypeError）与引用 claim 的更细粒度绑定。
